(Phases 31--40) covering: modified dispersion relations and Lorentz-
violation signatures; Hawking radiation budget per chronology horizon;
topology-change instanton actions; asymptotic-safety running of $G$;

with $\alpha$ scan + novelty catcher). A new always-on rule wires the
address-space spectral novelty catcher into every Systroph\=e module
and every hardware run. Code at \texttt{github.com/Zynerji/systrophe}
(v0.21.0+).

\section{Novelty catcher always-on (2026-05-11)}

A user-mandated durable rule, set 2026-05-11: every Systroph\=e
deliverable must run the address-space spectral novelty catcher
and report its verdict alongside the headline result. Implementation
at \texttt{src/systrophe/novelty\_catcher.py} (13 tests). Mechanism
(HASH-QUINE / tHHmL address-space rule):
\begin{enumerate}
\item Hash the output structure to integer bit-addresses.
\item Compute pairwise Hamming distances among addresses.
\item Build a Hamming-radius graph; compute $\lambda_2$ of its
  Laplacian.
\item Scan over the natural parameter axis; produce a $\lambda_2$
  surface.
\item Flag sharp $\lambda_2$ / Hamming-step jumps as candidate phase
  transitions / emergent structure / universality boundaries.
\end{enumerate}

Sharp-feature criterion (calibrated to suppress false positives):
Hamming step between successive parameter points must exceed median
$\times (1 + \theta)$ AND median $+ 2$ bits, where $\theta$ is the
user-configurable threshold. Verdict precedence:
\textit{uniform} $>$ \textit{novel\_structure} $>$ \textit{smooth}.

Address-space encoding caught the 2D Ising critical point in prior
HASH-QUINE work (1.4\% accuracy) where value-encoded paths gave null.
Phases 35--40 each include a \texttt{novelty\_scan()} entry-point;
their verdicts on the natural parameter axes are reported in the
per-module test outputs.

\section{Marrakesh batch 4: multi-band LP quantum walk}

Setup: 4 qubits (1 data + 3 path), 5 values of $\alpha$-scale in
$\{0.5, 1.0, \sqrt{3}, 2.0, 2.5\}$. Each band $n$ applies
CRZ(path$_n \to$ data, $n \cdot \alpha \cdot \ln 2$). Simulator
recovers each scan point's $\alpha$ to $<0.5\%$. Hardware run
pending (queue depth $\sim 43$ at time of writing).

Novelty catcher integrated into the analysis pipeline: bitstring
distributions from the 5 scan points are hashed to bit addresses and
$\lambda_2$ of the Hamming graph is computed. Predicted verdict:
\textit{smooth} (continuous parameter scan). Hardware-specific
deviations (e.g.\ noise-induced anomalies) would flip the verdict to
\textit{novel\_structure}.

\section{Pair-extinction universality (recurring theme)}

The same $(1 + \cos \delta)/2$ extinction factor now appears in
\emph{six} domains:
\begin{enumerate}
\item Classical $L_{\rm pair}$ extinction (Phase 4).
\item Spinor pair monodromy (Phase 19, hardware-verified batch 1).
\item ANEC integral collapse (Phase 27).
\item ER=EPR bridge strength / Bell-pair fidelity (Phase 35).
\item BMS soft-hair amplitude (Phase 36).
\item BH pair-production rate (Phase 37).
\item Anyonic braid phase (Phase 40).
\end{enumerate}

As noted in the body of Phase 35, this universality is mathematically
unsurprising: it follows from linear superposition of two identical
objects shifted by $\delta$. The single knob $\delta$ propagates
through every layer that depends linearly on the pair structure.
The interesting feature is the \emph{breadth} of the propagation:
classical GR, spin holonomy, QFT (ANEC), entanglement, asymptotic
charges, instantons, and topological order are all collapsed to a
single mechanism, $\delta = \pi$.
