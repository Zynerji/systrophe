\begin{abstract}
We add five further modules to the Systroph\=e framework
covering gravitational-wave emission, the averaged null energy
condition, the Page curve for CTC-enclosed regions, LQG-like discrete
area/volume spectra, and quantum tunneling out of CTC bands. In
parallel we report two batches of hardware experiments on the IBM
Marrakesh 156-qubit Heron processor that validate seven concrete
Systroph\=e predictions across spinor monodromy, Deutsch/Lloyd CTC
channel capacities, $Z_3$ cycle monodromy, KG cascade transmission,
KK-escape interferometry, and holographic phase-wrap extraction of
$\alpha = \sqrt{4a^2 - 1}$. Eighty-three new tests across the five
modules, all passing. Code at \texttt{github.com/Zynerji/systrophe}
(v0.20.0+).
\end{abstract}

\section{Gravitational-wave emission (Phase 26)}

A rigidly-rotating cylinder emits no GW at constant $\omega$; GW
emission arises from spin-up / spin-down, radial oscillation, or
binary inspiral. The module \texttt{gw\_emission.py} provides:
\begin{itemize}
\item \texttt{moment\_of\_inertia}: $I_{zz} = \tfrac{1}{2} M R^2$;
\item \texttt{spin\_up\_strain}: $h \sim 2 \dot\Omega \cdot I / D$;
\item \texttt{radial\_oscillation\_strain}: peak $h$ from radial mode;
\item \texttt{pair\_inspiral\_strain}: binary cylinder GW chirp;
\item \texttt{gw\_luminosity}: $P \sim (1/5)(\ddot I)^2 \omega_{\rm GW}^4$;
\item \texttt{detectable\_at\_distance}: SNR vs interferometer noise;
\item \texttt{cylindrical\_resonant\_frequencies}: radial-mode spectrum.
\end{itemize}

\section{ANEC integrated bound (Phase 27)}

For radial null geodesics on the LP exterior, we integrate
$T_{ab} k^a k^b / |k^r|$ from $r_{\min}$ to $r_{\max}$ using a
Hartle-Hawking-like vacuum stress tensor proxy. The module
\texttt{anec\_bound.py} provides:
\begin{itemize}
\item \texttt{T\_kk\_radial}: stress-energy null projection at $r$;
\item \texttt{anec\_integral\_radial}: integral over a radial path;
\item \texttt{anec\_quantum\_inequality\_bound}: Ford-Roman lower bound;
\item \texttt{anec\_integral\_circular\_null}: along F=0 closed null;
\item \texttt{pair\_extinction\_anec\_recovery}: ANEC restored at
  $\delta = \pi$ (extinction factor $(1+\cos\delta)/2 = 0$).
\end{itemize}

Headline: the Systroph\=e-pair extinction extends to ANEC: at
$\delta = \pi$ the effective ANEC integral vanishes, removing the
chronology-horizon contribution that would otherwise violate the
bound.

\section{Page curve for CTC region (Phase 28)}

Treating a chronology-enclosed region $r \in (r_n, r_{n+1})$ as an
``evaporating'' subsystem, we compute a toy Page curve $S(t)$ for the
entanglement entropy of enclosed quantum fields with the exterior.
The module \texttt{page\_curve\_ctc.py} provides:
\begin{itemize}
\item \texttt{enclosed\_region\_volume};
\item \texttt{bekenstein\_bound\_estimate}: $S_{\max} \sim 2 \pi R E$;
\item \texttt{page\_time\_estimate}: $t_P = S_{\max} / s_{\rm emit}$;
\item \texttt{entanglement\_entropy\_proxy}: $S(t) = \min(s_{\rm emit} t,
  s_{\rm emit}(T - t))$;
\item \texttt{information\_paradox\_resolved\_at\_page\_time}: $S$ decay check.
\end{itemize}

\section{LQG discretization (Phase 29)}

We compute the LQG-quantized area and volume on a constant-$t$ slice
of the LP exterior, with the Immirzi parameter $\gamma \approx 0.2375$
matched to black-hole entropy. The module \texttt{lqg\_discretization.py}
provides:
\begin{itemize}
\item \texttt{lqg\_area\_spectrum\_at\_j}: $A_j = 8\pi\gamma \ell_P^2 \sqrt{j(j+1)}$;
\item \texttt{lqg\_volume\_spectrum\_at\_j}: simple trivalent estimate;
\item \texttt{classical\_proper\_area}: $A_{\rm class}$ on LP cylinder;
\item \texttt{spin\_for\_classical\_area}: solve $A_j = A_{\rm class}$ for $j$;
\item \texttt{discretization\_error\_relative}: $|A_{\rm class} - A_j|/A_{\rm class}$;
\item \texttt{regge\_calculus\_deficit\_angle}: deficit per vertex.
\end{itemize}

For macroscopic slices ($j \gg 1$) the relative discretization error
is $\sim 1/j$, recovering the semiclassical limit.

\section{Quantum tunneling out of CTC (Phase 30)}

A particle confined in a CTC band $r \in (r_n, r_{n+1})$ classically
cannot escape -- the chronology horizons are turning points. Quantum
mechanically it can tunnel via WKB. The module \texttt{ctc\_tunneling.py}
provides:
\begin{itemize}
\item \texttt{effective\_radial\_potential}: $V_{\rm eff}(r) \sim 1/|F(r)|$;
\item \texttt{tunneling\_action}: $S = \int \sqrt{2m(V-E)}\,dr$;
\item \texttt{tunneling\_rate}: $\Gamma = \nu \exp(-2 S/\hbar)$;
\item \texttt{escape\_to\_chronology\_safe\_region}: $r_{\rm CH} \to r_{\rm safe}$;
\item \texttt{multi\_band\_tunneling\_diagram}: rates between adjacent bands;
\item \texttt{tunneling\_resonance\_locus}: search for resonant peaks.
\end{itemize}

\paragraph{Headlines.}
\begin{enumerate}
\item KK ($\xi$-velocity) escape from a 4D CTC into a 5D-spacelike
  path is verified by exact interference cancellation at the
  threshold $\phi_\xi = \pi$ (observed $P=0.500$ vs predicted $0.500$).
\item The complex conformal weight $\Delta = 1 \pm i\alpha/2$ of the
  holographic dictionary (Phase 16) is operationally reconstructible:
  $\alpha = \sqrt{3}$ is recovered to $\le 0.7\%$ across $N=1\dots4$
  steps including the $2\pi$ wraparound at $N \ge 3$.
\item Geometric decay across multiple chronology horizons holds
  within hardware noise ($\Delta \le 0.04$ per crossing).
\end{enumerate}

\paragraph{Calibration recipe.} \texttt{generate\_preset\_pass\_manager}
at \texttt{optimization\_level=3} (uses backend's live $T_1, T_2$ and
gate-error calibration to pick low-error qubits and routing), plus
modern \texttt{SamplerV2} options: \texttt{dynamical\_decoupling.sequence\_type
= XpXm} and \texttt{twirling.enable\_gates / enable\_measure}. All
circuits compiled to ISA depth $\le 48$ (well under the empirical
$<150$ Marrakesh-noise threshold).

\paragraph{Module bug fix.} The Marrakesh batch exposed a sign-convention
error in \texttt{spinor\_monodromy.spinor\_holonomy}: the heuristic
$\exp(-\pi/2 \cdot \omega \cdot \sigma_{ab})$ is non-unitary because
$\sigma_{01}$ is hermitian (boost generator) in $(-+++)$ signature.
Module now returns the polar-projected nearest unitary; new
unitarity test added.
